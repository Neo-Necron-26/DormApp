# Безопасность

Не публикуйте сведения об уязвимостях в открытых обсуждениях. Передайте описание сопровождающему репозитория приватным каналом GitHub Security Advisories.

При сообщении укажите затронутую версию, способ воспроизведения и возможное влияние. Не используйте реальные персональные данные и не проверяйте уязвимость на чужой инфраструктуре.

Демонстрационные аккаунты, локальная SQLite-база и платёжный сценарий не предназначены для промышленного использования. Перед развёртыванием необходимо заменить секрет JWT, включить HTTPS, ограничить CORS, подключить настоящий провайдер идентификации и провести отдельный аудит защиты персональных данных.
