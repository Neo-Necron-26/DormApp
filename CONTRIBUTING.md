# Участие в разработке

Спасибо за интерес к Dorm Campus. Проект состоит из нескольких npm workspaces, поэтому изменения в общих типах могут затронуть API, мобильное приложение и веб-панель одновременно.

## Локальная подготовка

```bash
npm install
npm run setup
npm run check
```

Создавайте локальные `.env` из соответствующих `.env.example`. Секреты, локальную базу и загруженные пользователями файлы нельзя добавлять в репозиторий.

## Структура изменений

- общие DTO, доменные типы и переводы размещайте в `packages/shared`;
- серверную валидацию и контроль доступа размещайте в `apps/api`;
- интерфейс студента и мобильную панель сотрудника размещайте в `apps/mobile`;
- desktop-интерфейс сотрудников размещайте в `apps/admin`;
- при изменении Prisma-схемы обновляйте seed и выполняйте `npm run setup`.

## Перед отправкой изменений

1. Проверьте, что интерфейс работает в светлой и тёмной теме.
2. Проверьте длинные русские подписи и узкую ширину экрана.
3. Проверьте доступ к функции для каждой затронутой роли.
4. Выполните `npm run check`.
5. Не включайте реальные персональные данные, ключи API и содержимое локальной базы.

## Сообщения об ошибках

В описании ошибки укажите роль пользователя, платформу, последовательность действий, ожидаемое и фактическое поведение. Скриншоты не должны содержать реальные персональные данные.
